# Week 9 Day 5: Portfolio Check-In #9

## Objective

Consolidate Week 9 deliverables covering cost optimisation, cost governance, migration planning, and migration monitoring. Review portfolio evidence to ensure FinTrust architecture decisions are supported by both technical implementation and business justification.

---

## Cost Optimisation Deliverables

### AWS Pricing Analysis

Completed pricing analysis using AWS pricing and TCO modelling techniques to compare on-premises infrastructure costs against AWS deployment options.

Deliverables completed:

- Pricing API automation
- Savings Plan calculations
- TCO break-even analysis

---

### Cost Reporting

Implemented automated reporting solutions using AWS Cost Explorer and Budgets APIs.

Deliverables completed:

- Cost Explorer reporting
- Monthly expenditure reporting
- Budget management automation

These reports provide ongoing visibility into cloud spending and support proactive cost management.

---

### Cost Governance

Implemented governance controls designed to improve cost accountability.

Deliverables completed:

- Tag compliance audits
- Service Catalog inventory reporting
- Governance reporting automation

These controls ensure resources can be allocated to the correct business units and monitored effectively.

---

## Migration Planning Deliverables

### 7Rs Migration Strategy

The FinTrust server estate was evaluated using the AWS 7Rs framework.

Migration strategies included:

- Rehost
- Replatform
- Refactor
- Repurchase
- Retire
- Retain
- Relocate

The assessment highlighted that not all workloads should be migrated using the same approach.

---

### DMS Monitoring

Developed monitoring solutions using AWS Database Migration Service APIs.

Monitoring capabilities:

- Replication task tracking
- Migration progress reporting
- Error detection
- Table validation monitoring

---

### Snow Family Planning

Created a Snow Family transfer planner for large-scale data migration scenarios.

FinTrust archive scenario:

- 3 PB regulatory archive
- 38 Snowball Edge Storage Optimised devices
- Approximately 2–3 week transfer window

This significantly reduces transfer duration compared to internet-based migration.
